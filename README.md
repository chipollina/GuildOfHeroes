## Собственный проект

#### Тема проекта: Коллекция фильмов 

#### Главный класс: `Films`

#### Почему этот объект нужен программе:
Класс `Films` описывает отдельный фильм и хранит все его характеристики в одном месте. Вместо того чтобы заводить по четыре отдельные переменные на каждый фильм (`name1`, `genre1`, `year1`, `rating1`, `name2`, ...), мы создаём один объект на фильм. Это позволяет легко добавлять новые фильмы, хранить их список и выводить информацию о каждом.

#### Какие данные хранит объект:

- `Name` — название фильма (string)
- `Genre` — жанр фильма (string)
- `Year` — год выхода (int)
- `Rating` — рейтинг фильма (double)

#### Какие значения задаются через конструктор:
Через конструктор передаются два значения, которые уникальны для каждого фильма и не могут быть заданы «по умолчанию»:

- название фильма (name) → сохраняется в поле `Name`
- рейтинг фильма (rating) → сохраняется в поле `Rating`

#### Какие значения можно задавать автоматически:

Внутри конструктора автоматически задаются:

Genre = "horror" — так как вся коллекция состоит из фильмов ужасов, жанр одинаков для всех объектов и не требует передачи при создании;

Year = 2018 — начальный год выхода, который при необходимости можно изменить позже через поле объекта.

Благодаря этому создание фильма сводится к короткой записи:
```csharp
Films film1 = new Films("The Nun", 5.8);
```

#### Какое значение я решила задавать автоматически и почему?

Я автоматически задаю жанр (Genre = "horror"), потому что все фильмы в моей коллекции относятся к одному жанру — ужасы. Передавать жанр в конструктор при каждом создании объекта было бы избыточно: это значение одинаково для всех фильмов. Если в будущем появится фильм другого жанра, поле можно будет изменить напрямую: film1.Genre = "comedy";.
